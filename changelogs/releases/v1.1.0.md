# response-cache-kit v1.1.0

Released: 2026-06-03

## Highlights

- Added response cache tags, tag invalidation, key deletion, stats, and remaining TTL APIs.
- Added `X-Cache` / `Cache-Control` header helpers and framework adapter helpers.
- Added a vext preset for millisecond-based route cache options, readable legacy keys, and 2xx-except-204 status behavior.
- Added `vary: "*"` for explicit all-request-header key variation.
- Expanded English and Chinese docs with full API, tag invalidation, adapter helpers, framework examples, and vext migration notes.
