# response-cache-kit v1.2.0

Released: 2026-06-03

## Highlights

- Added `cacheHub.mode: "redis"` and `"multi-level"` runtime options backed by `cache-hub@^2.2.0`.
- Added Redis lease coordination for cross-process same-key refresh protection.
- Added optional distributed tag invalidation and optional `cache.close?.()` lifecycle support.
- Changed `cache.clear()` to invalidate the current response cache namespace by internal tag, avoiding Redis `flushdb`.
- Fixed `Cache-Control` helpers so unstored responses never receive a new public `max-age`.
- Expanded English and Chinese docs with full Memory/Redis/MultiLevel/lease/distributed configuration, lifecycle notes, and Redis troubleshooting.
